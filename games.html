ⓘ How rewards work

Play games to earn rewards. Game scores, daily challenges, bonuses, and other Earnly activities can award Arcade Coins or XP.

Rewarded ads only unlock more chances to play. When you run out, you can optionally watch a rewarded ad for +3 plays, up to 2 unlocks per game each day. The ad itself does not directly give Arcade Coins.

How game progress works

Every finished game gives XP. Some game scores also earn Arcade Coins. Achievements, streak rewards, and weekly missions can add more XP.

Each game gets 3 free plays per day. Up to 2 rewarded ads per game can unlock +3 plays each without spending Arcade Coins. Progress stays on this device and is backed up automatically when you sign in.
