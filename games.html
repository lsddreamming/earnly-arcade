How game rewards work

Starting a game uses one play. When free plays run out, an optional demo rewarded ad can unlock 3 more plays. No Arcade Coins are required to keep playing.

Each game rewards a different skill: long runs, reaction speed, line clears, memory, survival, or brick clearing. The exact reward economy is still being tuned during the prototype.
